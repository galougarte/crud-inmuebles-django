# Proyecto Manejo del CRUD - Django

Sitio web para una empresa dedicada al arriendo de inmuebles. Permite a los usuarios registrarse como arrendatarios o arrendadores, publicar inmuebles, revisar la oferta disponible y filtrar por región y tipo de inmueble.

## Tecnologías usadas

- Python
- Django
- PostgreSQL

## Funcionalidades

- Registro e inicio de sesión de usuarios
- Perfil de arrendatario y arrendador
- Publicar, editar y eliminar inmuebles
- Listado de inmuebles disponibles
- Filtrado por región y tipo de inmueble

## Instalación

1. Clonar el repositorio
2. Crear y activar un entorno virtual
3. Instalar dependencias con pip install -r requirements.txt
4. Configurar la base de datos PostgreSQL en settings.py
5. Ejecutar migraciones con python manage.py migrate
6. Levantar el servidor con python manage.py runserver
